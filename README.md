# THINKING LAB — Public Site

공개 정적 사이트입니다. 분석 코드와 데이터 파이프라인은 비공개 저장소
(`hyun1077/THINKING-LAB`)에 있고, 여기에는 **공개해도 되는 화면만** 올라갑니다.

- `index.html` — 오늘의 리서치 질문 + 장기 시계열 (FRED 공식 이미지 직접 호출)
- `macro-terminal.html` — 금리·유동성·신용 환경 판정 기준선
- `assets/` — 썸네일 등 공개 이미지

원칙: 공식 장기 시계열 우선. 추정값을 사실처럼 표기하지 않습니다 (FACT ≠ MODEL).
